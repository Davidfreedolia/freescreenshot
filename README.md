## Català

**FreeScreenshot** és una eina de captura de pantalla minimalista per Windows. Una alternativa lliure i open source amb el nivell d'usabilitat que esperaries d'una eina de pagament.

### Què hi trobaràs

- Captura d'àrea, finestra, pantalla sencera, scroll
- Editor amb fletxes, rectangles, text, numeració, difuminat i més
- Pinned screenshots (captures flotants)
- OCR (extreure text de la captura)
- Gravació de vídeo i GIF
- Historial local
- Tot offline, sense compte, sense núvol

### Estat

Pre-alfa. El projecte arrenca el 2026. Mira [docs/ROADMAP.md](docs/ROADMAP.md) per veure on som.

### Requisits

- Windows 10 (1903) o superior
- Per desenvolupar: .NET 8 SDK + Visual Studio 2022 / Rider

### Posar-se en marxa (desenvolupadors)

```powershell
git clone https://github.com/Davidfreedolia/freescreenshot.git
cd freescreenshot
dotnet build
dotnet run --project src/FreeScreenshot.Tray
```

## English

**FreeScreenshot** is a minimalist screenshot tool for Windows. A free, open-source alternative with the usability you'd expect from a paid tool.

### Features

- Area, window, full-screen, and scrolling capture
- Editor with arrows, rectangles, text, numbering, blur, and more
- Pinned screenshots (floating overlays)
- OCR (extract text from screenshots)
- Video and GIF recording
- Local history
- Fully offline, no account, no cloud

### Status

Pre-alpha. Project kick-off in 2026. See [docs/ROADMAP.md](docs/ROADMAP.md).

### Requirements

- Windows 10 (1903) or later
- For development: .NET 8 SDK + Visual Studio 2022 / Rider

### Getting started (developers)

```powershell
git clone https://github.com/Davidfreedolia/freescreenshot.git
cd freescreenshot
dotnet build
dotnet run --project src/FreeScreenshot.Tray
```
